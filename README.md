# Gold Style Leuven

Website voor Gold Style Leuven ✂, Diestsestraat 204, 3000 Leuven. Kapsalon voor heren en dames.

## Gegevens van de zaak (verzameld 6 okt 2026)
- Telefoon: 0484 11 91 63
- Google: 4,7★ uit 65 reviews, **geen website of sociale media gelinkt**
- Uren (Google): ma–do 9–19, vr–za 9–20, zondag gesloten
- Logo op hun bord: "GOLD style" met een dames- en een herensilhouet, dus unisex

## Let op bij het verkoopgesprek
De recentste Google-reviews zijn gemengd (klachten over "niet luisteren"). Op de site staan alleen de rating en een positieve quote. Een website plus een duidelijke dienstenlijst kan helpen om verwachtingen beter te sturen. Dat is een goed verkoopargument.
